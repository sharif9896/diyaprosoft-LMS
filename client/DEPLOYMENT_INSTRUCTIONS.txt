DIYAPROSOFT LMS CLIENT - RENDER API CONFIGURATION

Production backend:
https://diyaprosoft-lms-4.onrender.com

Updated files:
- src/api.js: API requests and downloads use the configured API URL
- .env.production: sets the Render backend URL for production builds
- .env.development: keeps local /api calls via the existing Vite proxy

LOCAL DEVELOPMENT:
From the repository root (if npm workspaces are used), install dependencies and run your client as usual. Or from the client directory run:
  npm install
  npm run dev
Your local backend should run at 127.0.0.1:5000 for the existing Vite proxy.

PRODUCTION BUILD:
  cd client
  npm install
  npm run build

If client is deployed separately, configure the backend CORS allowed origins to include the client website domain. The backend must successfully start and connect to MongoDB Atlas.

If React and Express are on the SAME Render service, you can remove the value in .env.production (set VITE_API_BASE_URL=) to use same-origin /api, which is simpler and avoids cross-origin CORS.

Do not commit secrets or passwords into any VITE_ environment variables: values are embedded in browser assets.
